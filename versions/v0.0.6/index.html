This is the NULLSPACE debug menu

This menu is for debugging the game and reporting potential crashes or errors.

Below is a guide for what each tab is used for.




Game

Information about the game


System

Information about your system and performance


Debug log

Displays errors and warnings thrown by JavaScript


Diagnostic tool

Used to copy a diagnostic report of the game. When reporting a bug, send the report as well. It helps a lot when debugging and fixing bugs.
